구조 관찰 — 계획서 자신의 방침을 결함에도 적용한다

계획서 §01 의 방침은 "세 계측기는 같은 가정 하나를 공유한다 — 그 가정을 제거한다"였다. 같은 렌즈로 결함을 보면: D1(모서리 걸침) · D2(역포함) · D7(구멍 있는 호스트) · D8(rect→circle) · D9(자유곡선)는 전부 "호스트는 시트다"라는 한 가정의 증상이다.

근거는 코드가 스스로 적어 뒀다. circle_overlap.rs 머리주석: "On a SOLID's face the same draw is REFUSED: that re-derive is deliberately skipped wherever the affected region touches a solid, because re-arranging the region there re-cuts edges the solid's walls are standing on." — 시트에서 다 되는 이유는 arrangement (rebuild_coplanar_faces_analytic_scoped, scene.rs 의 δ-4a "sheet only")가 돌기 때문이고, 입체에서 일부만 되는 이유는 그 빈자리를 조합별 특수 경로가 메우기 때문이다 — 원×원 하나에 468줄(circle_overlap.rs), containment 4종 (assign_circle_holes_innermost · assign_polygon_holes · detect_circle_containment · detect_polygon_containment), convex 한정 auto_intersect_coplanar. 특수 경로가 없는 조합(D8·D9)이 정확히 안 되는 조합이다.

따라서

계획서 1·2단계를 개별 패치로 소진하지 말고, 분기 지점 특정(계획서 1단계의 원칙 그대로) → 입체 면 위 면-국소 arrangement(트랙 A) 로 푼다. D1·D2·D7·D8·D9 는 그 트랙의 합격 기준이 된다. 특수 경로를 하나 더 짜면(D8 용 rect×circle, D9 용 ellipse×…) 조합 수만큼 코드가 늘고, 다음 곡선 종류가 들어올 때 또 는다.

확장 트랙

전제 P PR #122 랜드 + 0단계(계측기) 완성 즉시 · 반나절

#122 없이는 어떤 측정도 계획서 수치와 비교 불가(R1). 0단계는 기존 계획 그대로 — face_area 곡선 배부름(Arc 닫힌 해 + 나머지는 곡선-현 일반식), point_in_face · face_bounds 자기루프 통로. wip 9241217 을 리뷰·회귀 붙여 완결한다.

트랙 A 입체 평면 면 위 — 면-국소 arrangement D1·D2·D7·D8·D9 · 2~3주 · 확장의 축

설계 원칙: 재유도(제거 후 재구축)가 아니라 in-place 분할. 입체에서 재유도가 꺼진 이유는 벽이 딛고 선 rim 엣지를 다시 자르기 때문이었다. 그러므로 호스트 면의 rim 은 보존하고, 내부에만 새 경계를 심는다. 이미 있는 부품으로 조립한다:

  • 2D 영역 계산 — boundary_kernel::analytic_arrange (line/circle 정확 CCI, freeform 포함). 시트가 이미 쓰는 그 코드다. 입력만 "호스트 면의 경계 + 그린 곡선"으로 국소화한다.
  • in-place 수술 패턴 — 특수 경로들이 이미 증명한 것: annulus 의 twin-loop reparent, circle_overlap 의 호 분해 + 중점 분할(2-edge bigon 회피). 일반화 대상이지 폐기 대상이 아니다.
  • 봉합 — t_junction.rs 의 heal_t_junction (이미 HARD 계약 준수).
  • 게이트 + 롤백 — guard_imprint 가 이미 스냅샷을 뜬다. 결과 판정만 watertight(소유 볼륨 한정)로 바꿔 단다.
AixiAcad 교훈
① 면마다 split → apply → heal 을 즉시 — 봉합을 미루면 이웃 면이 각자 정점을 만들어 봉합 불가가 된다. 같은 두 번의 절단이 봉합 시점만으로 "깨진 솔리드 대 완전한 watertight"로 갈린 실측이 있다 (surface_following_matrix.rs). ② heal 허용오차는 곡률 기반 max(1e-3, 3 × 최대 현오차) — 고정 1e-3 은 곡면에서 조용히 아무것도 안 한다 (실측: 실린더 세로 chord heal=0). ③ 실패 시 통째 롤백 — 부분 성공을 남기지 않는다.
산출물 형태
arrangement 가 처음부터 RebuildReport(FaceLineage 포함) 를 낸다 — 트랙 E 가 그 보고서를 소비해 소유권·재질을 승계한다. 소유권을 나중에 덧대는 게 아니라 op 산출물에 실어 나르는 구조 (ADR-312 정합).
은퇴 로드맵
합격 기준이 닫힐 때마다 특수 경로가 하나씩 은퇴한다 — circle_overlap(원×원) → containment 4종 → describe_overlap 의 우회 안내문. 각각 pinned 테스트가 "은퇴하라"고 알리는 구조(계획서 2단계 패턴)를 그대로 쓴다. 은퇴 전까지 특수 경로는 산 채로 대조군이다.
합격 기준
D1(바깥 조각 존재, 시트/입체 대칭) · D2(165,664 → 125,664) · D7(구멍 있는 호스트 위 중첩 그리기) · D8(rect→circle 순서 무관) · D9(타원·자유곡선, 시트와 동일 결과) · 기존 36조합 무회귀 · volume_face_count 불감소.
순서
착수 전 분기 지점 특정(계획서 1단계 원칙): 같은 입력을 시트/입체 두 경로에 넣고 region 목록이 갈라지는 지점을 확인한 뒤 시작한다. MVP 는 D8(rect×circle) — 가장 흔한 사용자 조합이고 대조군(circle×circle 특수 경로)이 살아 있다.

트랙 B 여러 면을 지나는 그리기 — 표면 각인 신규 능력 · 1주 · A 와 병행 가능

지금 우리 surface_path.rs 는 경로 계산까지만 한다 — 인접 2면을 unfold 해 꺾임점을 정확히 구하고, 인접하지 않으면 NotAdjacent 로 명시 거부한다. 각인(면 분할)은 없다. AixiAcad 의 imprint_surface_path 는 그 다음 절반이다: 경로를 같은-면 구간으로 묶고, 전이 접점을 먼저 전부 구해 양쪽 조각 끝에 넣고, 면 순서대로 split → apply → 즉시 heal, 마지막에 watertight 게이트 + 통째 롤백.

v1 한계 채택
AixiAcad 가 계측으로 확정한 한계를 그대로 갖고 시작한다 — 면을 완전히 가로지르지 않는 조각(열린 경로의 시작·끝 면)은 분할하지 않고 건너뛰며 기록한다. 같은 면 재방문 경로는 거부한다(첫 분할로 면 id 가 사라진다). 닫힌 경로(상자를 감는 띠)는 전 구간 완전 통과라 온전히 동작 — 이것이 대표 시연 사례다.
우리 부품
전이 접점 = surface_path unfold(평면 인접에서 정확해) · 면 내 분할 = split_face_by_chain(HARD 계약 이미 준수) · 봉합 = heal_t_junction · 스냅샷 = guard_imprint. 부족한 것은 오케스트레이션 함수 하나다.
합격 기준
상자 4면을 감는 닫힌 띠 → 새 면 생성 + 소유 볼륨 watertight 유지 · 모서리를 넘는 rect(두 면에 걸침) → 양면 각각 분할 · 실패 주입 시 byte-identical 롤백(변이 검증).

트랙 C 곡면 호스트 — 측정 먼저, 계약부터 D6 + 미측정 축 · D6 는 1일 · 즉시 가능

곡면 위 단일 도형 그리기는 이미 넓다 — 원은 4곡면 완료(ADR-202/257/263), 자유곡선·베지어는 open seam, OSNAP 도 곡면 위에서 동작한다(LOCKED #104). 곡면 위 도형 겹침은 0회 측정이다. 미측정을 결함으로 단정하지 않는다 — 측정 매트릭스가 먼저다.

C-0 측정
곡면 4종 × {원×원 겹침 · 원×원 포함 · seam 곡선과 교차} 매트릭스. ⚠ 계측기 함정: 곡면 면은 SURFACE 로 읽는 판독기(face_outer_area · face_bounds · face_outward_flux)만 쓴다 — 폴리곤 판독기는 곡면에서 거짓말한다(0단계의 교훈 그대로).
C-1 D6 fix
곡면 split 4종 + annulus.rs + carve.rs 에 HARD 부여 (기존 mark_edges_hard safe-OR 헬퍼 재사용) + Mesh::split_face 의 덮어쓰기 → OR 정리. 독립 작업, 언제든. 곡면을 원으로 자르면 seam 양쪽 normal 이 일치해 분할선이 렌더에서 숨는 정확히 그 케이스다. 변이 검증: HARD 를 빼면 wireframe 에서 분할선이 사라져야 한다.
C-2 곡면 겹침
C-0 결과에 따라, 트랙 A 의 면-국소 arrangement 를 호스트 파라미터 공간으로 확장한다 — 평면=평면기저(정확), 원통·콘=unroll(전개 가능이라 정확), 구·토러스=param+metric 보정. 이 3-tier 는 LOCKED #87 의 곡선 표현 정책과 같은 기준이라 새 정책이 아니다. AixiAcad 의 split_curved_face_by_curve (Planar/Cylindrical/Spherical/Cone 통일 진입 + wrap-around seam 처리)가 설계 참고.
C-3 곡면 위 직선
2-클릭 직선은 기하적으로 불가(측지선 degenerate — LOCKED #104, 재론 금지). rim→내부→rim 3-클릭 폴리라인은 실측으로 가능 — DrawLine 이 세그먼트마다 커밋하는 상태기계를 체인 수집으로 바꾸는 TS 작업이다. 별도 소단계.

트랙 D 기울어진 · 임의 평면 미측정 축 · 측정 반나절

36조합은 전부 z=0 또는 z=100 축정렬이었다. 3점 작업평면 (tool-plane)과 sketch offset/tilt 은 이미 있으므로(LOCKED #104), 비어 있는 것은 측정이다. AixiAcad 의 omni_plane_matrix 설계를 차용한다: 평면 4종(XY·XZ·YZ·비축정렬 사선) × 닫힌 도형 도구 전부, 판정은 "면 생성 + 법선 정합"만 — 면적 하드코딩은 취약해서 뺀다는 것까지 그대로. 사선이 핵심이다: 축정렬 3종만 재면 "축정렬 전용" 코드를 놓친다.

트랙 E 소유권 상속 — 계획서 3단계의 구체화 D4 · 1주 · A 산출물의 소비자

계획서 3단계를 유지하되 형태를 확정한다: 트랙 A 의 arrangement 가 내는 RebuildReport 를 단일 진실원천으로 삼고, 소유권·재질이 그 보고서의 lineage 를 따라 승계된다. AixiAcad 의 검증된 형태를 이식한다 — FaceLineage {Preserved / Split(Vec) / Merged / Removed} + vid-set 기반 매칭(좌표 무관 — centroid 휴리스틱을 명시적으로 deprecate 한 이력까지 참고 가치가 있다).

트랙 F 퍼즈 하네스 + 게이트 계획서 3.5 · 4 · 5단계 유지

계획서의 순서를 그대로 따른다 — 3.5(SI 판정 방향: 접촉≠손상 / coplanar 겹침=손상)를 확정한 뒤에만 4(그리기 롤백 게이트)를 켠다. 5단계 퍼즈는 AixiAcad fuzz_modeling.rs 구조를 이식한다: 결정적 LCG(seed 재현) × 100세션 × 50연산 × 매 연산 후 invariant 검증 + 실패 시 seed·op 로그. 36조합은 상상한 조합이고, 상상 못 한 조합은 이것이 답이다.
